# Workflow log

The agent maintains this file. It is evidence for improving the template after a real project; it is not a user form.

Add one compact entry for every `standard` or `complex` task and for a `quick` task only when a capability gate, review, or verification matters.

## Entry template

```text
Date:
Task:
Mode: quick / standard / complex
Profile and stack preset:
Workflows activated:

Capabilities
- Used:
- Not used:
- Missing or degraded mode:

Execution
- Plan/decision produced:
- Visual evidence and review file:
- Reviews run and findings:
- Verification commands and result:

Outcome
- Applied:
- Verified:
- Not applicable:
- Assumptions, risks, or follow-up:
```

Use observed facts only. Do not record a review, command, capability, or result that did not happen.
