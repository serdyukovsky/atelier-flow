# Visual review evidence

The agent creates one file from this template for each material visual direction or redesign in `docs/reviews/`.

```text
Date:
Scope and route:
Visual direction:
Paper aesthetic rule: prohibited / explicitly overridden by user
References used and the principle taken from each:

Visual slice
- Desktop screenshot (route, viewport, path or URL):
- Mobile screenshot (route, viewport, path or URL):

Independent review
- taste-skill: used / unavailable / not applicable
- UX reviewer findings:
- Anti-slop findings:
- Findings fixed:

Decision
- User decision: approved / revise / delegated to agent
- Evidence limitation or remaining risk:
```

Record only screenshots and review passes that actually exist.
