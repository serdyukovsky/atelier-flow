# CMS content model workflow

1. Confirm that a CMS is needed and select `cms-payload`.
2. Write a collection design before creating fields.
3. Define public, authenticated, editor, and admin access for every operation.
4. Define drafts, versions, preview, uploads, SEO, and migration impact.
5. Implement the smallest collection and test its access matrix.
6. Review Local API usage, hooks, file handling, and public serialization.
7. Verify admin editing, draft/public separation, rendered page output, and rollback expectations.
