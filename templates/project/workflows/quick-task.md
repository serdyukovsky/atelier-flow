# Quick task

Use for a small, local change.

1. Inspect the relevant code and project rules.
2. Implement the smallest correct change.
3. Select the `local` or `focused UI` scope from `verification-scope.md` and run the narrowest relevant check.
4. Report changed files, checks run or skipped with reason, and any assumption.

Do not start a full planning or multi-review cycle unless the change reveals broader risk.
