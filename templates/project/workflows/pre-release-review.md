# Pre-release review

Run the applicable reviews before deployment:

- functionality and acceptance criteria;
- typecheck, lint, tests, and build;
- browser/mobile visual review;
- SEO launch review for public sites;
- security baseline;
- authenticated-app or CMS review when selected;
- environment variables, migrations, backups, redirects, and rollback plan.
- real asset licenses, analytics, error monitoring, and deployment configuration.

The final report must distinguish `verified`, `not verified`, and `not applicable`.
