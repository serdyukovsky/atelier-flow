# MAX Mini App profile

Use for interfaces running inside MAX WebView. Treat this as a mobile-first product profile, not a marketing-site profile.

- Inspect the project's MAX SDK and current platform documentation before using platform APIs.
- Design for narrow screens, touch input, safe areas, theme adaptation, and WebView constraints.
- Define loading, empty, error, offline, and retry states.
- Keep first render fast and avoid decorative motion that harms performance.
- Verify navigation, viewport resizing, keyboard behavior, and deep links when relevant.
